# Method: Systematic Literature Study

A systematic review following Kitchenham and Charters [1], with snowballing as the search strategy, following Wohlin [2]. Each step uses one source, as written.

## Steps
| Folder | Step | Phase [1] | Source | Changes |
|---|---|---|---|---|
| `1-protocol/` | Review questions, selection criteria, quality checklist, extraction form | Planning | Kitchenham and Charters [1] | Rarely; changes are logged |
| `2-search/` | Start set and snowballing iterations | Conducting | Wohlin [2] | Every iteration |
| `3-reading/` | Three-pass reading, quality assessment, data extraction | Conducting | Keshav [3]; Kitchenham and Charters [1] | Every paper |
| `4-synthesis/` | Concept matrix | Conducting | Webster and Watson [4] | Every paper |
| `5-gap/` | Answers to the review questions, gap, history | Reporting | Kitchenham and Charters [1]; Webster and Watson [4] | When the matrix settles |

## Sequence
- 1 → 2 → 3 → 4 → 5. Steps 2–4 repeat per paper until the search stops.
- **Stop rule:** snowballing ends when an iteration finds no new papers [2].
- **Protocol first:** the protocol is written before searching, so selection does not bend to what you hoped to find [1]. Any later change to it is logged with its reason.

## IDs
- Review questions: SQ1, SQ2, …
- Papers: P1, P2, … in the order they are first found. Never renumber.
