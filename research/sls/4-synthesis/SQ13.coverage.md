# Coverage of SQ13

Saved as `sls/4-synthesis/SQ13.coverage.md`. Which papers serve this question, what each added, and whether the question has what it needs (`research/sls/4-synthesis/step.md`).

## Rule
- **Kind:** census.
- **Unit:** one many-core processor built without hardware shared memory or cache coherence whose cores communicate by messages or channels, with how it was programmed and why it was discontinued or not adopted.
- **Enough when:** every distinct processor is covered by one read paper, and a search round finds no new one. A processor counts as covered when the papers read for it say how it was programmed and why it was discontinued or not adopted, or when no paper found says so.
