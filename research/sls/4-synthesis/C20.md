# C20: Interrupts, exceptions and system calls turned into messages

## Definition
Hardware events, faults and traditional system calls are converted, by the kernel or the hardware, into messages to a handler that runs as an ordinary program. Merges "interrupts as IPC messages", "user-level device drivers" (two records), "interrupts integrated with message passing", "keeper", "event V-Thread", "message proxy library" and "sequence break".

## First found in
P46

## What the papers say, compared
- **Kernels convert interrupts.** In L4 "The kernel captures the interrupt but does not handle it, instead generating a message" for the associated user process, so drivers run in user mode and can be "replaced, removed, or added dynamically" (P46, p. 72); the practice is "Retained" after 20 years (P48, p. 139). Minix 3's handlers set a pending bit that "the kernel turns ... into a normal message" (P49, p. 48). Barrelfish's CPU driver demultiplexes device interrupts into messages (P8, p. 8).
- **Exceptions and system calls too.** KeyKOS delivers exceptions as messages to keeper domains (P53, p. 9). fos turns a traditional system call into a message to an OS server through a proxy library (P102, pp. 6–7).
- **Hardware can do it without a kernel.** The M-Machine handles translation misses, faults and message arrivals in a dedicated event thread "without stopping the thread" (P66, pp. 4–6).
- **Where it is not done.** On conventional microprocessors interrupts are "the only way to signal an asynchronous event", and the CM-5 polls because interrupts cost too much (P33, pp. 433–434, 439). The Lisp Machine keeps sequence breaks, "a kind of interrupt" (P73, p. 429). EROS enters the kernel per trap because of the Pentium's "irregular" saved state (P77, p. 178). Helios steers every interrupt to one coordinator (P45, pp. 5–6).
- **Comparison.** In every kernel read the trap or interrupt is first taken by privileged code and only then becomes a message, so the conversion sits on a base that is not a message (C42); only the M-Machine moves it into hardware.
