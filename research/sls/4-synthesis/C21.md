# C21: Single-stack, event-driven kernel

## Definition
The kernel runs on one stack with no per-thread kernel state, handling each event to completion. Merges "CPU driver" (as an event-driven kernel), "event-based (single-stack) kernel", "lazy scheduling / Benno scheduling" and "interrupt-style kernel".

## First found in
P8

## What the papers say, compared
- **Three lineages converge.** Barrelfish's per-core CPU driver is "privileged, event-driven, single-threaded, nonpreemptable" (P8, p. 8). L4's newer kernels replaced the process kernel by an event kernel with continuations ("Replaced: Process kernel by event kernel in seL4, OKL4 and NOVA") (P48, p. 144). EROS has "no per-process kernel stack": a suspended process restarts at the trap instruction (P77, p. 178).
- **Above the kernel, the same idea.** fos servers run each transaction to completion and store a continuation instead of blocking (P102, p. 7).
- **Scheduling follows.** L4 moved from lazy scheduling to "Benno" scheduling for a bounded worst-case execution time (P48, pp. 144–145).
- **Comparison.** The papers agree on the structure but give different reasons: verification and bounded timing (P48), per-core independence (P8), the processor's trap format (P77). None measures it against a kernel with per-thread stacks.
