# C38: Register windows

## Definition
Overlapping register sets used as activation frames, so calls need not save registers to memory. Merges "register windows for frequent calls", "overlapping register windows", "spilling rules" and "pointer to register".

## First found in
P11

## What the papers say, compared
- **SOAR depends on them.** "SOAR would run 46% slower without them", because Smalltalk compiles to many calls (P11, pp. 43, 67, 70); it uses 16-register fully overlapped windows with simple spilling rules and hardware mapping registers to memory addresses (P261, pp. 3–4, 7, 10).
- **The contrast cases.** The 432 has no data registers, to save chip space and speed process swaps (P10, pp. 302, 318); the J-Machine's evaluators name the "paucity of registers" as a limit (P65, p. 11); and in message-driven processors a context lasts only one handler, so "large register sets cannot be used" (P33, pp. 435–437).
- **Comparison.** Call-heavy language machines gain from many registers, while message-driven ones cannot keep them busy; this is a design tension for any machine whose primitive is a send (C1, C7).
