# C30: Stateless kernel and single-level store

## Definition
The kernel holds no critical state of its own; all state lives in persistent objects, and kernel data is only a cache of them. Merges "stateless kernel", "single-level store" (two records), "the kernel owns no state" and "software caching of objects".

## First found in
P53

## What the papers say, compared
- **KeyKOS.** The kernel holds "no critical state"; its private storage "is merely a cache of the persistent state"; "all data lives in persistent virtual memory" and only the nanokernel knows main memory from disk (P53, pp. 2–3).
- **EROS, its successor.** "With the sole exception of the list of stalled processes ... the EROS kernel owns no state"; even the process table "is a cache", and persistence is transparent to applications (P77, pp. 170, 175–178).
- **Comparison.** Both papers come from one lineage and agree; no independent paper read evaluates the idea.
