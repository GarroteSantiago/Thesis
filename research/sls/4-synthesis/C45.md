# C45: Duality of message passing and shared memory

## Definition
The claim that message-based and shared-memory structures are equivalent, or each can be built from the other. Merges "message-passing/shared-memory duality", "actors and closures are the same concept" (as equivalence) and "coexistence of communication paradigms".

## First found in
P8

## What the papers say, compared
- **Cited, not tested.** Barrelfish cites Lauer and Needham: the two OS models are duals, and the machine architecture decides between them (P8, p. 3). The original paper (P18) is unread.
- **Each side claims the other maps onto it.** "any program that works for ... message passing systems (e.g., MPI cluster) can easily map to a shared memory system with caches" (P22, p. 8). Active Messages are "more primitive" than send/receive and shared memory and implement both (P33, p. 431). EROS models a load or store as "an efficiently cached capability invocation" (P77, p. 173). The MDP claims the advantages of both (P69, p. 196; P64, p. 12).
- **Equivalence with exceptions.** Actors equal closures except for state and synchronisation (P15, pp. 17, 63).
- **Swapping is used to fix bugs, not shown equivalent.** Go developers fix shared-memory bugs with channels and channel bugs with shared variables (P9, pp. 8, 11).
- **Coexistence in practice.** Message passing and scratchpads persist in niches beside dominant coherent shared memory (P22, pp. 1, 8).
- **Comparison.** Every statement read is an argument; none measures whether encapsulation, freedom from races or interposition survive the translation, which is what the duality question needs (see C43, C44).
