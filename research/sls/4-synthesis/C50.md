# C50: Software-managed coherence and non-coherent on-chip memory

## Definition
On-chip memory shared by cores without hardware coherence, with software invalidating or tracking cached lines. Merges "Message Passing Buffer (MPB)", "Message Passing Memory Type (MPMT)", "INVDMB instruction", "software-maintained coherency" and "block status bits".

## First found in
P21

## What the papers say, compared
- **The SCC.** Each tile has 16 KB of on-die shared memory; cache lines marked MPMT can all be invalidated in one cycle by a new instruction, and "Shared memory coherency is maintained through software in an effort to eliminate the communication and hardware overhead required for a memory coherent 2D-mesh" (P21, pp. 173–177).
- **The M-Machine** caches remote data in local memory under software control with two status bits per 8-word block (P66, p. 9).
- **The analysts' reply.** Removing coherence moves complexity into software, and incoherent scratchpads persist only in real-time niches (P22, pp. 1, 8–9).
- **Comparison.** The designers (P21) give no measurement of the saving; the analysts (P22) give no measurement of the software cost. Both are open.
