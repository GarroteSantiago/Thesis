# Need for the review

## What the review is about
Message abstractions (objects and actors that own their state and talk only through messages) are used in languages, agents and networks, but the operating system, the instruction set and the hardware underneath still expose threads, shared memory and primitives that are not messages. The review collects the systems that tried to carry message semantics below the language (into the kernel, the instruction set or the hardware): how far down each got, what non-message primitives it kept, how it performed, and why it was abandoned or not adopted.

## Existing reviews
| Review | What it covers | Why it is not enough |
|---|---|---|
| Levy (1984). *Capability-Based Computer Systems*. Digital Press. | "An introduction, a survey, a history, and an evaluation of capability- and object-based computer systems" (p. vii): B5000, Plessey 250, CAP, Hydra, StarOS, System/38, Intel 432 (pp. vii–viii). | Its focus is capability addressing and protection, not message passing as the only means of communication (pp. vii–viii). Published 1984: it misses the J-Machine (1992), multikernels (2009) and everything after the end of Dennard scaling. It is a narrative survey with no stated selection method. |
| Ditzel, Patterson (1980). *Retrospective on High-Level Language Computer Architecture*. 7th International Symposium on Computer Architecture, 97–104. | Survey and critique of high-level-language computer architectures (as described in Wikipedia's "High-level language computer architecture" article; full text not reached, see open issues). | Covers language-directed machines before 1980, not message-based or actor machines, operating systems, or multicore. No stated selection method (unverified, full text not read). |
| Li, Zhang, Li, Fong (2012). *Object-Oriented Programming Hardware/Software Supports and Comparison*. 2nd International Conference on Computer and Information Application (Atlantis Press). | Compares three ways to support object-oriented programs: compilation to native code, software virtual machines, and object machines (abstract). | Concerns executing objects faster on one processor; does not cover message passing, actors, operating systems, or multiple cores (abstract). Not a systematic review. |
| De Koster, Van Cutsem, De Meuter (2016). *43 Years of Actors: A Taxonomy of Actor Models and Their Key Properties*. AGERE 2016 workshop, SPLASH. | History and taxonomy of actor languages and libraries in four families: classic actors, active objects, processes, communicating event-loops (p. 1). | Language and library level only. States its goal "is not to provide an exhaustive overview of every actor system in existence" (p. 1). Does not cover kernels or hardware. |
| de Boer et al. (2017). *A Survey of Active Object Languages*. Association for Computing Machinery Computing Surveys 50(5), article 76. | Compares four major actor and active object languages along chosen dimensions of the paradigm and its implementation (abstract, CWI repository record). | Language level only; covers no operating system or hardware (abstract). |
| Tong (2025). *Descriptor-Based Object-Aware Memory Systems: A Comprehensive Review*. arXiv 2510.27070v2. | Survey of descriptor-based, object-aware memory systems as a way to bridge the semantic gap across the hardware/software interface: memory protection, management and processing (p. 1). | Covers memory objects and descriptors, not messages between objects or actors, nor the operating system (p. 1, Fig. 1 p. 2). |

No systematic review (Kitchenham-style) was found on message semantics below the language level.
