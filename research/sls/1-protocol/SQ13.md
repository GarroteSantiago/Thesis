# SQ13

## Question
Which many-core processors were built without hardware shared memory or cache coherence, communicating between cores by messages or channels, how were they programmed, and why were they discontinued or not adopted?

## Why it matters to the observation
Hypothesis H3 says this design is different because it targets many cores with no shared state. That target has been built before: the Inmos Transputer with occam channels, and Intel's 48-core Single-chip Cloud Computer, a message-passing processor without cache coherence (Howard et al., 2010, ISSCC). If such chips were dropped for reasons that still apply, H3 does not separate this work from earlier failures.
